# Artemis.Blam.Map

Group `2_Blam` - pure static library (mostly generated) - reads the Halo Reach `.map` file format.

## Responsibility
Opens the `.map` files the engine opens (the map, `shared.map`, `campaign.map`), reads their header and tag index, and fills a
frozen tag catalog with the raw struct of every tag that has a descriptor. The tag structs and their descriptors are generated by
`Tools/TagTranspiler` from the Assembly plugin XMLs. zlib (compressed sections) is compiled here, its only user.

## Does not
- Know when the game opens a map or where MCC is installed: the owner reports the path the engine opened.
- Interpret tags or resolve the game's tag handles: that is `Blam.MapModel`.

## Input and output
- Input: the full path of each cache file the engine opens (`MapLoaderService::OpenFile` sorts it by name).
- Output: the stores of `Blam::Map::Layer`: open files, tag index and the frozen `TagCatalog`.

## Public interface
Other projects may import only these modules; everything else in the project is internal. Outside `Blam.MapModel` only `Mod`,
the development tools and the tests may import them.

| Module | What it gives |
|---|---|
| `Blam.Map.Layer` | The facade: stores and services of the loaded map; `Cleanup()` forgets it. |
| `Blam.Map.Reader.Type`, `Blam.Map.Reader.State`, `Blam.Map.Reader.System` | File header, tag index, data streams and tag references. |
| `Blam.Map.Tag.Type`, `Blam.Map.Tag.State`, `Blam.Map.Tag.System` | Generated tag structs, the catalog and the tag readers. |

## Depends on
`Common`.

## State between ticks
None: one map at a time, kept until `Cleanup()`.

## Threads
`OpenFile` runs on the thread that reports the file (the game thread, inside the open-map hook): it reads the header and the index
only. `LoadForMap` fills the catalog on the AI thread when the map loads. Afterwards everything is read-only.

## Errors
A missing or truncated file logs an ERROR ("Could not open map file." / "Failed to load map.") and the map stays not loaded;
nothing downstream uses it.

## Requirements
- Reads only the files it is given; touches nothing else on disk.
- ~47k generated lines: compiled apart so changes elsewhere never rebuild it. Generated files are regenerated, not edited
  (`GenerateTags.py --check`).

## Tests
`MapTests` in `Artemis.Tests`, with real `.map` files (`ARTEMIS_REACH_MAPS` or the Steam folder, checked by size and CRC-32;
skipped when absent): the log lines of a load of `forge_halo`, truncated files, sorting by name, `Cleanup`.
